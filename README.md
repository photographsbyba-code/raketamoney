# Raketa Money International

Static concept showroom for Raketa Money. Three starter snapbacks and the deep-blue tracksuit, with a 1998-inspired international street-luxury website. No store, prices, checkout, chain or watch.

## Run and edit

Open `index.html` or serve this directory with a static HTTP server. Product definitions are at the top of `script.js`; images are in `assets/`. All artwork depicts unmanufactured concepts.

## Hosting

GitHub Pages publishes `main` from the repository root. There is no build step, backend, analytics or paid service dependency.

The intended custom domain is `raketamoney.com`. Do not set the GitHub Pages custom domain until the DNS cutover is ready. At Wix, the apex A records must point to 185.199.108.153, 185.199.109.153, 185.199.110.153, and 185.199.111.153; the `www` CNAME should point to `photographsbyba-code.github.io` without the repository path. Preserve unrelated mail and verification records.

GitHub setup: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

Wix DNS instructions: https://support.wix.com/en/article/connecting-a-wix-domain-to-an-external-site

## Public content

This repository contains only website files and optimized concept images. It does not include source print files, the necklace artwork, user attachments or private account data. Raketa Money is an independent concept label, not an official watch-manufacturer collaboration.
